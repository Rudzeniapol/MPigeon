# MPigeon - Chat Application using Sockets in C++

MPigeon is a simple chat application implemented in C++ using Winsock2.h for socket programming. This project demonstrates how to create a basic client-server chat system where multiple clients can connect to a server and exchange messages in real-time.

## Features

- **Real-time messaging**: Clients can send and receive messages instantly.
- **Multi-client support**: The server can handle multiple clients simultaneously.
- **Simple command-line interface**: Easy-to-use interface for sending and receiving messages.
- **Cross-platform compatibility**: Designed for Windows using Winsock2.h.

## Prerequisites

Before you begin, ensure you have the following installed:

- **Windows OS**: This project uses Winsock2.h, which is specific to Windows.
- **C++ Compiler**: Such as GCC, Clang, or MSVC.
- **CMake** (optional): For building the project.
